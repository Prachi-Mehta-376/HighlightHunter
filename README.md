# HighlightHunter

## Overview
HighlightHunter is a beginner‑friendly computer‑vision web app that lets students upload photos of their study notes, detect highlighted sections, extract the highlighted text, and generate a revision PDF.  The core detection, OCR, and PDF generation are **placeholders** for now – the UI and project scaffolding are fully functional.

## Features (Sprint 1)
- Streamlit UI with modern purple‑lavender theme
- Image upload (JPG, JPEG, PNG) with preview
- Sidebar controls
- Buttons to trigger placeholder detection, extraction, and PDF generation
- Modular code structure (`detector.py`, `extractor.py`, `pdf_generator.py`)
- Ready for unit testing with `pytest`

## Setup Instructions
1. **Clone the repo** (or download the folder).
2. Open a terminal in the `HighlightHunter` directory.
3. (Optional) Create a virtual environment:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate   # Windows
   ```
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the app:
   ```bash
   streamlit run app.py
   ```
   The app will be reachable at `http://localhost:8501`.
6. Run the placeholder tests:
   ```bash
   pytest
   ```
   All tests should pass (they only check that placeholder functions return the expected types).
